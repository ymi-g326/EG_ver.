# EARTH GROOVE × NUCC

地球がレコード。てんこう2が、その針。

NUCC（N.U Cosmic Campus）向けに、Earth Grooveを独立したフォルダへ複製した開発版です。公開されたてんこう2の軌道から位置を推定し、その直下の地表画像と気象モデルを自然音・シンセによる音楽へ変換します。

## 既存版との関係

元の版: `../EARTH_RECORD_v0.1`。このフォルダはソース・ロゴ・自然音を複製して作成しました。

Gitの履歴・リモート、`.vercel`、`.env*`、旧ホスティング接続、公開用スクリプトを引き継いでいません。NUCC版をローカルで編集・起動しても、元のフォルダや公開中のVercelサイトは更新されません。`vercel.json` は一般的なNext.jsビルド設定で、既存プロジェクトのIDや接続情報を持っていません。NUCC版を公開する際は、別のGitリポジトリと別のVercelプロジェクトを作成してください。

`COPY_ORIGIN.json` に複製元ファイルのSHA-256を記録しています。既存版が変更されていないことを照合できます。

## 起動

Node.js 22.13以降、pnpm 11.25以降を使用します。

```bash
pnpm install --frozen-lockfile
pnpm dev
```

このMacでは依存パッケージも独立したファイルとして複製済みです。そのまま起動できます。

開発用管理画面: http://127.0.0.1:3101

`pnpm dev` で管理サーバーとNUCC版を起動します。管理画面のON / OFFでNUCC版だけを起動・停止でき、停止しても管理画面は残ります。NUCC版の画面をその中に表示します。

通常のNUCC版URL: http://127.0.0.1:3100 。直接開いた開発画面の右下にも管理画面へのリンクを表示します。公開ビルドでは表示しません。

管理サーバーは127.0.0.1:3101だけで待ち受け、このプロセスから起動したNUCC版だけを停止します。別のプロセスが3100番を使用中なら停止せずエラーを表示します。ターミナルでCtrl+Cを押すと管理サーバーとNUCC版の両方を終了します。

管理機能を使わず起動する場合: `pnpm dev:app`。この場合は管理画面のON / OFFの対象にはなりません。

```bash
pnpm typecheck
pnpm test
pnpm build
pnpm start
```

## 最初のNUCC版

- ISSから `TEN-KOH 2 / NORAD 68261` へ切り替え。CelesTrak、次にSatNOGSの公開TLEを取得。
- 対象衛星番号、TLEのチェックサム、軌道データの日時を検証。7日を超えたデータや別の宇宙機のTLEを拒否。
- 通信障害時は2026年10月14日に取得した実際のTLEを利用。画面に「保存済みの軌道を使用」と表示。保存TLEも7日を超えれば使用せず、取得待ちを表示。
- 暗い背景、黄緑とシアン、世界地図、音の軌跡、自然音とシンセの4声を継承。
- 日本語の導入、てんこう2の紹介、「地球を聴く」、輪郭／地表の表示切り替え、作品説明を追加。
- 軌道または地表画像が未取得の間は再生待ち。位置未取得時に架空の衛星位置を表示しない。

## データと位置づけ

これはNUCC向けに制作中の作品案です。てんこう2から写真や音声を直接受信するシステムではありません。音楽はブラウザで生成します。NASAの地表画像は表示された観測日の画像で、ライブカメラではありません。雲・風・波などは地表の気象モデルで、衛星搭載センサーの計測値ではありません。

- NUCC: https://aero.cst.nihon-u.ac.jp/okuyama/nihon-cosmic-campus/
- てんこう2: https://aero.cst.nihon-u.ac.jp/okuyama/en/research/%E3%81%A6%E3%82%93%E3%81%93%E3%81%86%EF%BC%92/
- 軌道: https://celestrak.org/NORAD/elements/gp.php?CATNR=68261&FORMAT=TLE
- 予備の軌道データ: https://db.satnogs.org/satellite/BLJD-2583-9512-2426-1509/
- 地表画像: NASA GIBS、VIIRS SNPP True Color
- 地表気象: Open-Meteo、CC BY 4.0。無料APIの利用条件に従う。
- 自然音: FreesoundのCC0音源。作者・出典・変換は `public/audio/earth/README.md` に記載。
- オープンソース: satellite.js（MIT）、Lucide（ISC）、React（MIT）等。

実際のてんこう2の写真・受信コンテンツ・テレメトリの取り込みは、今後、利用可能な素材とデータ経路が確認できた段階で追加する対象です。

## テンポと開発用の音モニター

- サウンド操作部でAUTO / 手動を切り替えます。AUTOは風速0/3/6/10/15/20m/sを80/95/110/125/140/150 BPMへ補間し、毎秒最大10 BPMで追従します。風欠測は直前BPM維持、初回欠測は80 BPMで待機します。
- 手動は80〜150 BPM。再生中にも変更でき、AUTOに戻すと環境への連動を再開します。
- 開発時のみ画面右下に「開発用 · データ → 音」を表示します。公開ビルドでは表示しません。
- モニターでは公開TLEの基準日時、位置の計算日時、NASA画像の観測日・解析日時、気象API応答の受領日時と適用地点を区別します。てんこう2からの直接受信はまだ行っていません。
- 音エンジンが計算した基準音、フィルター、余韻、発音密度、履歴数と、再生時刻に到達した発音指示を表示します。出力メーターはブラウザ内の信号を測定します。OSのミュートやスピーカー音量は測定しません。
- 風速はAUTOに使用します。波高・風向・海流速度は、現状の発音処理では未使用であることを表示します。新たな録音素材・衛星実測データの追加は未実装です。


## 地表と雲の分離・固定条件の試聴

- 自然音と楽器の土台は海・植生・乾燥地・混合地表。雲量で雷雨録音へ置き換えません。海陸はworld-atlasの縮尺1:1億1000万の地図で概算します（小島・海岸の精度には限界があります）。
- 画像の明るい低彩度画素を雲候補として、地表色の解析から除きます。雪や砂との誤判定があり得る簡易推定です。植生・乾燥地も画像色による推定で、土地被覆の実測分類ではありません。
- 地表が隠れた際は同じ2度セル内の直前の地表値を保持。記憶がない陸地は中立の混合地表音、海は基準の海の音を使い、開発モニターで区別します。
- 海でも陸でも、適用雲量35%以下で長調、65%以上で短調へ切り替え、中間は直前の調を保持します。明るさ・昼夜は調判定から外しました。晴れは上向きで短い旋律、曇りは下向きで長い旋律。各拍に主旋律を置き、画像特徴で間の音と打音を追加します。残響は控えめにし、自然音の土台を保ちます。AUTOのBPMは風速に連動します。
- 開発画面左下の「開発用 · 固定条件で試聴」から、海・植生・乾燥地・その他の陸地について、それぞれ晴れ／曇りの8条件を比較できます。合成条件であることを常時表示し、直接受信データと混同しません。
- 試聴中は手動BPMを共有し、切替時にフレーズと録音の開始位置をそろえます。同じ海・森のペアは地表値・緯度・気温を固定し、雲量から長短調・旋律・響きの違いを作ります。ライブの履歴は音に混ぜず、地図・実環境データは実際の取得値のままです。
- 「実環境に戻す」で試聴前のAUTO／手動設定を復元します。試聴は開発中だけ使え、ページを再読み込みすると解除されます。公開ビルドには試聴操作と音モニターを表示しません。


## 風速と地形の確認（2026-10-21）

- 現在の風はOpen-Meteoの `wind_speed_10m`。単位m/s、地表から10mの高さのモデル値。突風ではなく、記録値の上限は切っていません。AUTOのBPMは風速に割り当てました。気温は表示・記録のみです。
- 取得地点は推定位置を緯度・経度それぞれ1度単位に丸め、地点が変わるたび取得。同地点では60秒おき。上流は同じURLを600秒キャッシュする指定です。風のモデル対象時刻・刻み・単位をAPI応答へ残すようにしました。
- 開発用モニターの「風速の振れ幅・取得間隔」は、このページで成功した受領データを最大512件記録。同地点・同じモデル時刻の重複、欠測を除外し、最小・中央値・P90・最大、記録間隔、風速帯別件数を表示。JSON保存可能。再読込でリセットし、合成試聴値を混ぜません。
- `MIXED TERRAIN` は山岳の意味ではなく、植生・乾燥地以外の混合・未分類の陸地、および雲で不明な陸地の受け皿です。日本語表記を「その他の陸地」にし、石の打音による合成試聴を晴れ・曇りで追加。乾燥地の曇りも追加しました。
- 起伏は標高データから算出する別軸です。雪氷・都市の個別判定は未接続です。画像の濃淡・輪郭を地形の高低差と扱わないでください。

## 風連動BPM・起伏・海岸

- 風速の結節点の間は線形補間し、20m/s超は150 BPM。手動は80〜150 BPMを即時適用します。画面では再生中の実際のBPMと目標値を分け、開発ログも発音時に使用したテンポを記録します。
- `GET /api/terrain` は1°単位の地域中心と周辺0.8°の9点をOpen-Meteo標高APIで照会します。同じ地点は7日間のキャッシュ指定。高低差150m以下を中立、2000m以上を最大の音楽用起伏係数とします。標高だけで高原を険しい山とは扱いません。
- 地形の取得は気象と独立し、周辺に陸がある場合に照会します。現在の地点と異なる古い地形は音に適用せず、未取得・失敗時は中立で継続。標高は音域を、起伏は旋律のオクターブ跳躍・和音の配置・合間の音の密度を変えます。
- 海岸は簡略地図の周辺6°・49点で海陸割合を概算し、波と陸地の自然音を混ぜます。山頂や細い岸線、小島の精密な検出ではありません。陸の割合が小さいほど起伏の効果を弱めます。
- 開発試聴では8つの地表・晴曇条件に、平地／山岳・起伏、海岸の混合割合、合成風速、風AUTO／手動を重ねて変更できます。初期は手動固定で比較し、「風でAUTO」で風速とテンポを試します。合成値を実際の位置・地形・風の取得履歴へ混ぜません。
- 地形出典：Copernicus DEM GLO-90 / Open-Meteo（https://open-meteo.com/en/docs/elevation-api）。静的な90m標高モデルで、てんこう2の直接観測ではありません。


## 地表のテーマ音の試作（2026-10-21）

- 主旋律を、植生・森ではハープ風の弦の撥音、海では音程のある水滴・泡へ変更しました。ブラウザで合成するオリジナルの音色で、ハープや水滴の新規録音素材ではありません。波・葉の既存CC0録音を背景に重ねます。乾燥地・その他の陸地は従来の主旋律です。
- 同じ旋律・長短調・発音タイミングを保ち、ハープは高い倍音ほど早く減衰、水滴は冒頭の短い上昇音から基準音へ落ち着く設計です。雲の長短調、風のBPM、起伏の跳躍、海岸の自然音混合を引き継ぎます。海岸で楽器自体を混ぜる処理はまだありません。
- 開発用の固定条件試聴に「テーマ音／以前の音色」「全体を聴く／主旋律だけ」を追加しました。切替時はフレーズと録音位置をリセットし、BPM・雲量は保持します。「主旋律だけ」は背景録音・ベース・パッド・打音を止めた比較です。実環境へ戻すと通常のテーマ音と全体演奏へ戻ります。
- 音モニターに主旋律の楽器名と発音ログを追加。比較操作は公開ビルドには表示しません。

## 展示用ローカルモード（2026-10-21）

- `http://127.0.0.1:3100/local` を直接開き「演奏を開始」を押します。通常ビルドでも利用でき、開発用試聴に依存しません。最初の1回はスタッフの再生操作が必要です。
- インターネットの接続は不要です。端末のNUCCサーバーとブラウザを起動しておく必要があります。ローカルページは衛星軌道・NASA画像・気象・標高のAPIを呼び出さず、同梱地図・音源・8つの合成風景を使います。実衛星の現在位置は表示しません。
- 8条件を一巡するまで重複せずシャッフルし、周回の境目でも同じ風景を連続させません。各45〜90秒演奏後、次の小節の先頭で移行します。自然音と合成音はフェードで移り、風景ごとの合成風速からAUTOが滑らかに追従します。手動80〜150 BPMも使用可能です。
- 「次の風景へ」は再生中なら次の小節、停止中なら即座に切り替えます。一時停止中は風景の残り時間も止まります。山岳・海岸はこの最初のローカル構成には含めず、8条件の聴感確認を優先します。
- 長時間運転のため、使用終了した音声ノードの接続を解放し、音色キャッシュは最大48件、表示履歴は16場面に制限しました。タイマーが大きく遅れた場合は過去の音をまとめて鳴らさず、小節を再開します。
- 開発時のみ「開発用 · 連続演奏の状態」に再生時計・場面転換・遅延復帰数・音源数・出力・発音ログを表示します。公開ビルドでは運転確認欄を出しません。
- 会場準備は `pnpm build`、当日は `pnpm start` で起動し `/local` を開きます。再読込後は再生ボタンを押します。開発時は従来どおり管理画面3101から起動可能です。
