# EARTH GROOVE PF

2026-11-09に提出済みの `EARTH_GROOVE_NUCC_V2` から分けた、PF用の独立したGitリポジトリ。
元のV2・NUCC版・EARTH_RECORD_v0.1は変更しない。元のGitリモート・公開先は引き継がない。
UIは現状を保ち、通信・音声・スクラッチの不具合修正を優先する。

PF版はURL共有による閲覧用。検索エンジンには `noindex, nofollow, noarchive` を指定する。
URLを受け取った人はアクセスできる。認証による閲覧者制限ではない。

## GitHub Pages版

`pnpm build:pages` で `dist-pages/` にLIVEとLOCALの静的アプリを生成する。
GitHub Pagesの公開元は `gh-pages` ブランチのルート。`main` には開発ソースを保存する。
ソースのpushだけではPages版は更新されない。変更後はビルドした成果物を `gh-pages` へ反映する。

画面・音源・AudioWorkletはGitHub Pagesで配信し、軌道・NASA画像・気象・起伏は
既存のPF用データサーバー `https://earth-groove-pf.sorriso-2870.chatgpt.site/api/` を利用する。
埋め込みや転送ではなく、同じReactコンポーネント・音声エンジンをブラウザで実行する。
公開データAPIには認証なしGET用のCORSヘッダーを付ける。LOCALは外部APIを利用しない。
検索除外の指定はPages版にも維持する。

## 起動

- `pnpm dev`：PF管理 http://127.0.0.1:3301/ と PF本体 http://127.0.0.1:3300/
- `pnpm dev:app`：PF本体のみ起動。
- `pnpm build`：PFサイト公開用のWorkerを `dist/` に生成。
- `pnpm build:next` / `pnpm start`：Next.jsの本番ビルドと3300番での起動。
- 現行版の3100 / 3101、V2の3200 / 3201とは独立して操作する。
- `node_modules` も独立したAPFS複製。元フォルダへのシンボリックリンクではない。

## V2の体験

「眺めていると地球が音楽を奏で、触れると少しだけ音に触れられる。」

- LISTEN：回せる地球儀のレコード、再生・音量・AUTO/手動BPM。
- INSPECT：元のデータ・音の詳細画面へ。同じエンジンを維持して切り替える。
- 地球儀を回してもLIVEの演奏場所は変わらない。衛星の推定位置が針の役割。
- SCRATCH：ボタンをONにして地球を左右にこする。アプリ内の直前約1秒を前後再生。AudioWorklet非対応環境では合成音プレビュー。外周の溝からも操作可能。マイク・外部送信・永続録音は使わない。
- キーボード：地球儀の矢印キーで視点回転。SETTINGSの「スクラッチを試す」で音の操作を試せる。
- AMBIENT：自然音の連続した層、疎らな旋律、長い柔らかな和音。打楽器なし。
- GROOVE：同じ地表・雲・風の対応に、控えめな低音とブラシ音の拍。
- 風によるAUTO（AMBIENT：80–100、GROOVE：80–150 BPM）、雲の長短調、地形・海陸混合、森のハープと海の水滴は継承。
- LIVE再生中のスクラッチは、手や矢印キーを離すと待たずに衛星へ帰還を開始。強い横回転は速度と向きを引き継ぎ、同じ方向へ周回しながら減速してLIVEに合流する。停止中の自由回転と「ここを聴く」で選んだEXPLOREは最後の操作から10秒で自動帰還（移動3.6秒）。
- LIVE：てんこう2（68261）の公開軌道から現在位置を推定。NASAの観測画像と地表気象モデルで地上生成。
- LOCAL：`/local`。保存した合成風景8条件のシャッフル。衛星の現在位置・実際の気象とは無関係。
- LIVE / LOCAL は明示的に切り替える。取得失敗時の自動偽装や別衛星への代替はしない。

## 検証

`pnpm typecheck`、`pnpm test`、`pnpm build`。
V2テストでは視点と位置の分離、音のスタイル、スクラッチ、2時間の仮想連続演奏を確認する。
仮想時計の試験は実機で2時間音を出した検証とは異なる。
展示用スピーカーでの音量・低音・耳疲れと、長時間の実再生は別途確認する。

音源のクレジットは `public/audio/earth/README.md`。
引き継いだV1の記録は `README-v1-origin.md`。
